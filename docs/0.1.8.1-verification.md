# 0.1.8.1 — placement and timer presentation

- Explicit native persistence replaces reliance on Neutralino's saved state. Normal window bounds, monitor name and work-area origin are atomically saved in `data/window.json` when changed, while hidden, and on Exit. Minimized/maximized bounds do not replace normal bounds. First launch without this file centers normally. A rearranged monitor preserves its relative offset; a disconnected monitor falls back to a clamped, centered primary-screen placement. A failed write is logged without exposing the path or monitor name.
- Ascending Status order is Spawned, Spawn window, Waiting, Outdated, No data. Descending reverses it.
- Changed/new rows highlight for two seconds with a brief opacity dip and a lighter background returning to the table color. Refreshing only Gathered at triggers it. Identical polling snapshots and ordinary clock ticks do not restart it; meaningful status transitions do. Reduced-motion preference removes the opacity dip.
- Gathered time uses ten 15-minute age bands, green through yellow/orange to red (0–15, 15–30, …, 135+ minutes). Age is measured from gathered time, independently of the kill-based expiry rule. Outdated immediately overrides with muted red; its discarded timestamp is shown as a dash. Hover still provides full date/time and age in minutes.

Validation: both TypeScript projects, 72 Bun tests (including a compiled native placement regression test) and 12 Convex tests pass. Native tests cover serialization, negative monitor coordinates, monitor rearrangement/removal, smaller working areas and invalid bounds. Timer tests cover ordering, freshness boundaries and detecting gathered-only/attribution changes. Windows x64 compilation and portable archive/version/privacy/help-link inspection pass. No Convex schema/function change or redeployment is needed.

Only local release folders/ZIPs for 0.1.8 and 0.1.8.1 are retained. Live multi-monitor restoration, animation appearance and the other [user checks](windows-validation.md) remain manual acceptance tasks; they were not claimed as tested here.
